Olá, sejam bem vindos ao meu projeto final do curso Web-Moderno, siga os passos abaixo para executar em sua máquina:

1. fazer clone do projeto
2. executar npm i
3. no arquivo env_file, copie e cole no mesmo local, renomeie a cópia para ".env" e complete os espaços com os dados em que sua máquina pode hospedar o back-end
